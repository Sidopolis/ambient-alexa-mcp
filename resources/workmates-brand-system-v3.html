Brand Design System — v3.0

Workmates

Palette and type derived by pixel-sampling the current logo mark: indigo figures, gold accents, deep ink-navy wordmark, ember orange as tertiary accent. Five surfaces: website, PowerPoint, Word/legal documents, Excel, PDF.

Source: uploaded logo mark, sampled directly (#4B39FF, #FDBE1B, #1F1F53) — not estimated.
01

Color System

Indigo is the primary brand color — used for the people-icon mark and as the dominant UI color. Gold is a single, deliberate accent, not a co-equal second color. Ink-navy replaces pure black for the wordmark and body text.

Ratio guide: ~65% white/mist, 25% indigo, 8% gold, ≤2% ember orange. Gold never carries body text — at #FDBE1B its contrast against white fails accessibility for text; it's a fill/accent color only, never a foreground text color. Orange follows the same rule and stays rarer than gold — it's a tertiary signal, not a second CTA color.

What the mark is actually built from, so it's reproduced consistently rather than redrawn from memory each time.

ElementDetail

06

Usage Guardrails

Correct

Gold appears once per view as a genuine accent (a badge, a dot, an icon detail). Indigo carries primary actions. Ink-navy for all real text — gold is never used as text color.

Avoid

Gold body text or gold buttons with white text (fails contrast), overcrowding the logo's clearspace, redrawing the icon with equal-height figures (the staggered heights are intentional).

07

Extended Data & Semantic Palette

Indigo, gold, and slate alone can't distinguish more than 2–3 series in a chart or dashboard. Extend with tints/shades of the same two hues rather than introducing off-brand colors — keeps multi-series charts recognizably "Workmates." Status colors (success/warning/error) are kept intentionally separate from the brand palette so a red warning is never confused with a brand color choice.

08

Cross-Media Application

The web tokens above don't transfer directly to PPT or Word. Two things break by default: fonts (Google Fonts aren't installed on most machines) and color (screen RGB isn't print CMYK). This section is the fix for both, per surface.

SurfaceFont handlingColor handling
Website Load Poppins + Inter via Google Fonts <link> — renders correctly for every visitor, no action needed. Use hex/RGB tokens as-is.
PowerPoint Google Fonts are not pre-installed on most Windows/Mac machines. Either embed fonts in the .pptx (File → Options → Save → Embed fonts) or design against the fallback stack below — do not assume Poppins will render on a client's laptop. RGB tokens work directly (screen-only medium) — enter hex values in Slide Master theme colors.
Legal / Word docs Same embedding problem, worse consequence — a legal document with substituted fonts can shift pagination and look unprofessional. Embed fonts (Word: File → Options → Save → Embed fonts) or use the fallback stack. If the document may be printed, use CMYK values, not RGB — see §10.
Fallback font stack (use when fonts can't be embedded): Poppins → Montserrat → Trebuchet MS → Calibri. Inter → Calibri → Arial. Montserrat is the closest free-and-usually-preinstalled match to Poppins's geometric structure.

PowerPoint System

Slide Master specs for a 16:9 deck. Build these once as an actual .potx template in PowerPoint rather than reformatting each new deck by hand.

ElementSpec
Canvas1920 × 1080px (16:9), safe margin 80px on all sides — nothing critical (logo, text) inside that margin.
Title slideInk-navy (#1F1F53) full background, white Poppins 800 headline, gold underline rule (4px) beneath the title, wordmark bottom-left, "WORKMATES" wordmark-only lockup — never the full icon+wordmark at this scale unless it's the actual title.
Section dividerIndigo (#4B39FF) full background, white Poppins 700 section title, gold slide-number badge top-right.
Content slideWhite background. Header bar: Poppins 600, 28px, ink-navy. Body: Inter 400, 18px minimum (never smaller — back-of-room legibility), ink-navy or slate. One indigo or gold accent element per slide max (a rule, an icon fill, a chart series) — not both competing.
Data/chartsPrimary series: indigo. Secondary series: slate (#666B85). Gold reserved for the one data point you want to call out — a highlighted bar, a "you are here" marker. Never use gold for a full series; it fails contrast against white slide backgrounds when used as thin lines or small text labels.
FooterPlex Mono 10px, slate, left-aligned: confidentiality line + slide number. Right-aligned: wordmark, 16px height max.
10

Word & Legal Document System

Contracts, SOWs, MSAs, compliance letters. This surface trades personality for unambiguous readability and print reliability — brand presence is restrained to letterhead and footer only.

ElementSpec
Page setupA4 or Letter per jurisdiction, 1 inch (2.54cm) margins on all sides — standard for legal readability and binding/printing tolerance.
Body typefaceDo not use Poppins or Inter for contract body text. Use a conservative serif or system sans required by legal convention — Times New Roman 11–12pt (formal/court-facing) or Calibri 11pt (internal/commercial contracts). Brand typography is confined to the letterhead and headers only.
LetterheadWordmark-only lockup, max 28px height, top-left. A single 2px indigo rule beneath the header block. No gold, no icon at this size — the four-figure icon degrades below ~24px.
Headings within docSection headings (e.g. "1. Definitions") in the body typeface, bold, ink-navy — not Poppins. Consistency with the legal body face matters more than brand voice here.
FooterPlex Mono or Calibri 9px, slate: company registered name, page X of Y, confidentiality notice.
Watermarks"DRAFT" or "CONFIDENTIAL" — ink-navy at 8–10% opacity, diagonal, never gold or indigo at full strength (interferes with legibility and photocopying).
Signature blockPlain body typeface, no color, no styling. This is the one place brand identity should be fully absent — signature blocks are legal artifacts, not design surfaces.
11

Excel / Spreadsheet System

Excel treats custom fonts poorly across machines and templates are frequently copy-pasted between files, breaking formatting. Optimize for a system font and let color carry the brand identity instead.

ElementSpec
FontCalibri or Aptos (Excel's current defaults) at 10–11pt for data, 11pt bold for headers. Don't fight Excel's native font — it breaks on copy/paste between workbooks and across OS.
Header rowFill: Ink Navy (#1F1F53) or Indigo (#4B39FF). Text: white, bold. Freeze this row on any sheet over ~20 rows.
Row bandingAlternate white / Mist (#F5F5FC) — not indigo or gold, which is too heavy repeated across dozens of rows.
Chart seriesUse the six-color extended palette from §07, in that order, as the default chart color cycle.
Conditional formattingUse standard semantic red/green from §07 for positive/negative, over/under-budget, status flags — not brand indigo/gold. Finance readers expect standard traffic-light logic; don't make them relearn it for brand consistency.
KPI/summary cellsGold fill, ink-navy bold text, is acceptable for a small number of "headline number" cells (e.g. total ARR) — this is one of the few places gold-as-background-with-dark-text works well outside digital UI.
12

PDF Output

PDF isn't its own design system — it inherits rules from whatever generated it. The only brand decision is which source rules apply.

PDF sourceRule
Exported from web / design toolMarketing collateral, one-pagers, proposals designed as standalone documents. Full brand system applies — Poppins/Inter, indigo/gold, embed fonts on export so they don't fall back on the recipient's machine.
Exported from WordContracts, SOWs, formal letters. Inherits §10 rules exactly (Times New Roman/Calibri body, restrained brand presence) — the PDF export step changes nothing about the formatting decisions already made in Word.
Exported from ExcelReports, financial summaries. Inherits §11 rules. Set print area and scaling before export — Excel's default PDF export frequently cuts off columns.
Print-intended PDFIf it's going to a physical printer, use CMYK values from §14, not the RGB tokens used everywhere else.
