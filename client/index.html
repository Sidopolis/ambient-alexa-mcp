PLATFORM & ARCHITECTURE GUIDE

How Ambient Works

Self-hosted Model Context Protocol (MCP) server & autonomous Alexa+ agent powered by AWS Bedrock for the Amazon Developer Hackathon.

01

Simulated Alexa+ Surface

Accepts natural voice or text commands. Ambient plans multi-step routines, remembers user preferences across sessions, and renders dynamic interactive UI cards.

02

Streamable HTTP MCP

Full implementation of the late 2025 MCP specification. Uses bidirectional Server-Sent Events (/sse) for real-time streaming and JSON-RPC 2.0 (/messages) for tool calls.

03

Bedrock Quota Failover

Zero-downtime multi-model cascade: Claude 3.5 Sonnet → Amazon Nova Pro → Claude Haiku → Gemini → Offline Simulator. Try the "Simulate Quota Limit" pill in the header.

04

Observability & Digital Twin

Sub-500ms execution trace waterfall captures reasoning, tool dispatches, and SSE latency. Power Grid & Device Topology offer live smart home telemetry.
